Повтор накапливает, последовательность flow очищает

При выбранном законе count повторов прамады добавляют count единиц. Последовательность flow очищает конечную наледь. Это условный расчёт; доступность таких действий человеку и срок восстановления не доказаны.

pramada-grows : ∀ count ice → run count ice (λ _ → pramada) ≡ count + ice
pramada-grows zero ice = refl
pramada-grows (suc count) ice = trans (pramada-grows count (suc ice)) (+-suc count ice)

grip-grows : ∀ count ice → run count ice (λ _ → grip) ≡ count + ice

Опора - условие восстановления

recover требует другого спутника с открытым проходом. Свидетельство поддержки - явная предпосылка операции; её наличие не гарантируется.
Проверенный фрагмент Agda
record Support {C : Circle} (g : Gathering C) (p : Circle.Person C) : Set where
  constructor supported-by
  field
    companion : Circle.Person C
    other : ¬ (companion ≡ p)
    available : passage g companion ≡ unlocked

-- Reopening a passage does not take the participant outside. The witness is
-- required by this operation itself, not only by the RawStep wrapper.
recover : ∀ {C} (g : Gathering C) (p : Circle.Person C) → Support g p → Gathering C
recover {C} g p support = record g
  { passage = update {C} (passage g) p unlocked }

Признание обратимо

revocable предъявляет наблюдения: первое окно соответствует критерию, следующее - нет. Это конкретный свидетель обратимости, не теория психологии.
Проверенный фрагмент Agda
revocable : Σ Observations (λ o → Recognized o 0 1 × ¬ Recognized o 1 1)
revocable = o , initial , withdrawn
  where
    o : Observations
    o t = mkObs (pred t) 0 0

    initial : Recognized o 0 1
    initial = record { duration = s≤s z≤n ; steps = step }
      where
        step : ∀ {i} → i < 1 → Improving (o i) (o (suc i))
        step {zero} _ = flat (mkObs 0 0 0)
        step {suc i} (s≤s ())

    withdrawn : ¬ Recognized o 1 1
    withdrawn r with Improving.gap-narrows (Recognized.steps r {0} (s≤s z≤n))
    ... | ()

-- Equal endpoint scores can no longer hide regression within a window.
interior-regression : Observations
interior-regression zero = mkObs 0 0 0
interior-regression (suc zero) = mkObs 1 0 0
interior-regression (suc (suc _)) = mkObs 0 0 0

endpoints-agree : interior-regression 0 ≡ interior-regression 2
endpoints-agree = refl

interior-not-recognized : ¬ Recognized interior-regression 0 2
interior-not-recognized r with Improving.gap-narrows (Recognized.steps r {0} (s≤s z≤n))
... | ()

  field
    identity : ℕ
    recognition : Recognition

acknowledge : Beast → Beast

beast-preserved b = refl

acknowledged-not-shadow : ∀ b → ¬ InShadow (acknowledge b)

  human : ℕ → ShadowItem -- a rejected human feeling, not a beast

Окончательное оттаивание - свойство будущего

Siddha означает EventuallySiddha: начиная с некоторого момента нет ни хватки, ни прамады. Это свойство бесконечной истории, а не вычисляемый диагноз сегодняшнего состояния.
Проверенный фрагмент Agda
SiddhaFrom : History → ℕ → Set
SiddhaFrom h T = ∀ t → T ≤ t → h t ≡ flow

EventuallySiddha : History → Set
EventuallySiddha h = Σ ℕ (SiddhaFrom h)

-- Compatibility alias for the original theorems; its precise meaning is EventuallySiddha.
Siddha : History → Set
Siddha = EventuallySiddha

Refutes : ℕ → History → Set
Refutes n h = ∀ h′ → Agrees n h h′ → ¬ Siddha h′

Достаточность и минимальность заданы отдельно

Proportionate требует остановить остаточный вред, выбрать наименьшее ограничение и не наносить лишнюю рану при равном ограничении. Это формальная политика выбора.
Проверенный фрагмент Agda
record Proportionate (p : Problem) (a : Action p) : Set where
  field
    adequate : Adequate p a
    least : ∀ b → Adequate p b → restriction p a ≤ restriction p b
    -- Among equally restrictive actions, do not choose a greater injury.
    least-wound : ∀ b → Adequate p b → restriction p b ≡ restriction p a → wound p a ≤ wound p b

Угроза прошла - ограничение снимается

При нулевой угрозе idle становится достаточным конкурентом. Отсюда выводится нулевое ограничение. Это вывод о текущем ограничении, а не об отмене прошлого вреда.
Проверенный фрагмент Agda
released-choice : ∀ p a → Proportionate p a → threat p ≡ 0 → restriction p a ≡ 0
released-choice p a justified clear = n≤0⇒n≡0
  (subst (restriction p a ≤_) (idle-level p)
    (Proportionate.least justified (idle p) (trans (idle-residual p) clear)))

Admissible исключает enclosure по выбору конструкторов. compression-not-admissible следует из этой политики, а не доказывает невозможность плохой ночи.

data Admissible {C : Circle} {g : Gathering C} : ∀ {h} → RawStep g h → Set where
  allow-approach : ∀ {ready} → Admissible (approach-step ready)
  allow-exit : ∀ {p h} {e : Exit g p h} → Admissible (exit-step e)

  allow-recover : ∀ {p ready support} → Admissible (recover-step p ready support)
  allow-rekindle : ∀ {ready} → Admissible (rekindle-step ready)
  allow-explosion : ∀ {ready input effective shape} →
    Admissible (resolve-step ready input explosion effective shape)

Допустимые шаги сохраняют проход

Из безопасного начального состояния допустимый шаг сохраняет возможность выйти каждому. Это доказательство для выбранных переходов; взрыв не совершает за человека его личный выход.
Проверенный фрагмент Agda
admissible-preserves : ∀ {C} {g h : Gathering C} (step : RawStep g h) →
  Admissible step → EscapeInvariant g → EscapeInvariant h
admissible-preserves (approach-step _) allow-approach safe = access⇒escape (escape⇒access safe)
admissible-preserves (exit-step e) allow-exit safe = access⇒escape (leave-access (escape⇒access safe) e)
admissible-preserves (reframe-step _) allow-reframe safe = access⇒escape (escape⇒access safe)
admissible-preserves {C} {g} (recover-step p _ support) allow-recover safe =
  access⇒escape (recover-access {C} {g} p support (escape⇒access safe))
admissible-preserves (rekindle-step _) allow-rekindle safe = access⇒escape (escape⇒access safe)
admissible-preserves {g = g} (resolve-step _ input explosion effective shape) allow-explosion safe =
  access⇒escape (burst-access g shape)

record CollectiveRule (Person : Set) : Set₁ where
  field
    Input : Set
    choice : Input → Person → Choice
    ReturningPower GrippingPower : Input → Person → Set
    -- A returning catalyst must make its own reclaim choice. Other participants
    -- need not agree; kashaya may remain effective despite a reclaim intention.
    returning-choice : ∀ input p → ReturningPower input p → choice input p ≡ reclaim
    Responds : (Person → Position) → Input → Outcome → Set
    explosion-origin : ∀ positions input → Responds positions input explosion →
      Σ Person (λ p → positions p ≡ inside × ReturningPower input p)
    enclosure-origin : ∀ positions input → Responds positions input enclosure →
      Σ Person (λ p → positions p ≡ inside × GrippingPower input p)
